# Usability test with teachers (Phase 5)

Goal: check that a teacher who has never seen Haajari can mark a class of 40 in under 30 seconds, and find
what slows them down. Plan: 3 teachers, about 15 minutes each, on their own phones if possible.

## Setup

- Site open on the teacher's phone, logged out. Language: Kannada (they can switch).
- Give them a teacher login: `9000000007` / PIN `1234` (4-A, 40 children).
- A printed slip with 3 roll numbers to mark absent, e.g. **5, 12, 28**, and one late: **20**.
- Stopwatch. Do not help unless they are stuck for 30 seconds; note where.

Say: *"We are testing the app, not you. Please think aloud."*

| # | Task | Success | Time (s) | Taps | Stuck where? |

| 1 | Log in with the number and PIN | Home screen shown | | | |
| 2 | Mark today's attendance for 4-A: 5, 12, 28 absent, 20 late | Saved screen shown | | | |
| 3 | You made a mistake: 12 is actually present. Fix it. | Saved, with a reason | | | |
| 4 | Find who was absent last Monday | Past days opened, Monday found | | | |
| 5 | Find which children need a follow-up and record that you called one parent | Follow-up saved | | | |

Timing for task 2 starts when they tap the 4-A slate and stops when the *saved* screen appears. Target: under 30 s.
